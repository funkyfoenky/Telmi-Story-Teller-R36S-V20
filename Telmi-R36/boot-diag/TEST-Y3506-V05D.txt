# Test Y3506 — y3506-v05d (DSI stock)

Image : **0.6.7** (ou 0.6.6 + DTB copie manuelle)
Bootdiag : **DESACTIVE** (pas de fichier TELMI-BOOT-DIAG)

## Fichiers sur BOOT

1. Copier `y3506-v05d.dtb` → **`rf3536k3ka.dtb`**
2. `TELMI-REV.txt` = **y3506-v05d** (une ligne)
3. `TELMI-AUDIO-PATH.txt` = **HP**
4. Supprimer `TELMI-BOOT-DIAG` si present
5. **Optionnel (image >= 0.6.8)** : `Enable-Panel-Diag.bat` pour logs panel

## Boot

- Ejecter, demarrer la console
- Attendre **30-40 secondes**
- NE PAS s'attendre a des logs utiles dans telmi-runtime.log
